# TecnoPreço

Comparador inteligente de preços de tecnologia — release v156.

## Conteúdo
- Frontend/PWA futurista
- Backend Node.js
- API `/api/v1`
- Catálogo e ofertas
- Autenticação e sessões
- Estrutura para alertas e sincronização de preços
- Docker / Docker Compose
- Testes de contrato

## Segurança
Nunca comitar passwords, tokens, chaves de API, ficheiros `.env` ou bases de dados reais. Usa `backend/.env.example` como referência.

## Execução local
```bash
cd backend
npm install
npm start
```

Consulta `backend/README.md` para a configuração completa.

> Os preços e integrações externas devem ser configurados com fontes autorizadas antes de uma utilização em produção.
